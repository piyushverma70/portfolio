# Project Specification: Portfolio (Piyush Verma)

## 1. Project Overview & Objective
* **Project Name:** Portfolio
* **Tier:** `3D_WEBGL_INTERACTIVE`
* **Target Audience / Purpose:** Personal Developer & Creator Showcase (AI Engineering, High-End Web, 3D Interactive)
* **Estimated Budget / Scope:** High-End 3D Portfolio
* **Created Date:** 2026-11-24

---

## 2. Technical Stack & Architecture
* **Frontend Framework:** Vite + React (TypeScript)
* **Styling & UI Kit:** Tailwind CSS, Glassmorphism, Custom Glows & CSS variables
* **3D & Canvas:** Three.js / @react-three/fiber, @react-three/drei, GLSL Shaders / Canvas Particle System
* **Animations:** Framer Motion, GSAP (ScrollTrigger), Lenis Smooth Scroll (Cinematic video-like pacing)
* **Icons:** Lucide React
* **Backend / Contact:** Lightweight Serverless / EmailJS / Web3Forms API (Zero server maintenance)
* **Deployment Target:** Vercel / Cloudflare Pages

---

## 3. Key Sections & Requirements
- [ ] **Hero Section:**
  - Interactive 3D Canvas / Cyber Particle Core (responds to mouse movement & scroll).
  - Cinematic headline with glowing gradient typography.
  - Resume button, Quick Action CTA, and Status Indicator (Available for work / Building AI).
- [ ] **About / Philosophy Section:**
  - Video-type cinematic text reveals & scroll-driven stats.
  - Deep-dive into AI systems, autonomous agents, and fullstack engineering.
- [ ] **Featured Projects Showcase:**
  - 3D Tilt cards, video/interactive previews.
  - Featured projects: **Venus AI**, **Midnight Checkout**, etc.
  - Live demo & GitHub links with tech tags.
- [ ] **Interactive Tech Arsenal:**
  - Floating 3D/Glow skill badges & category filter.
- [ ] **Interactive Contact Portal:**
  - Sleek glassmorphism contact form.
  - Direct email integration, social links (GitHub, X/Twitter, Discord).
- [ ] **Audio / Ambiance (Optional toggle):** Subtle cyber ambient sound effects / toggle.

---

## 4. Design Guidelines & Aesthetic
* **Color Palette:**
  - Background: Obsidian Black (`#0a0a0f`, `#050508`)
  - Accent Primary: Electric Cyan / Neon Teal (`#00f0ff`, `#00ffcc`)
  - Accent Secondary: Ultraviolet / Purple (`#8a2be2`, `#bf00ff`)
  - Glass: `rgba(255, 255, 255, 0.03)` with border `rgba(255, 255, 255, 0.1)`
* **Typography:** Syne / Space Grotesk / Inter
* **Design Tone:** Futuristic, High-End Cyberpunk, Immersive & Ultra-Smooth
