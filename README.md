## 🌿 Highlights & Architecture

- **Visual ASMR & Comfort Aesthetic:** Warm minimalist `#FAF8F5` palette, tactile frosted glassmorphism, and dual-side converging scroll physics.
- **Organic 3D Layer:** Floating matte pastel spheres with soft directional lighting rendered in Three.js WebGL (`Hero3DCanvas.tsx`).
- **High SEO Optimization:**
  - Rich OpenGraph and Twitter Card tags.
  - JSON-LD Structured Data for Google indexing (`Person`, `WebSite`, `ProfessionalService`).
  - Search engine discovery via `robots.txt` and `sitemap.xml`.
- **Full Mobile Responsiveness:** Touch-first navigation with an animated frosted drawer menu, responsive typography, and centered hCaptcha.
- **Inquiry & Lead Channel:** Fully functional project builder with budget selection, hCaptcha bot protection, and Web3Forms API submission.
- **Featured Works:**
  - 🏆 **Kashish Masale & Spices** (Shankar Food Products) — Live production commercial website (`https://kashishbyshankarfoodproducts.co.in/`).
  - 🤖 **Venus AI** — Autonomous Desktop AI Assistant (Personal R&D project).

## 🛠️ Tech Stack

- **Framework:** React 19 + TypeScript + Vite
- **Styling:** Tailwind CSS + Custom ASMR Design System
- **Smooth Scroll:** Lenis Smooth Scroll
- **3D & Canvas:** Three.js (WebGL)
- **Animations:** Framer Motion + Canvas Confetti
- **Bot Protection & Forms:** `@hcaptcha/react-hcaptcha` + Web3Forms API
- **Icons:** Lucide React + Bespoke SVG Monograms

## 🚀 Getting Started

### 1. Clone & Install
```bash
git clone https://github.com/piyushverma70/portfolio.git
cd portfolio
npm install
```

### 2. Configure Environment Variables
Copy `.env.example` to `.env`:
```bash
cp .env.example .env
```
Fill in your credentials:
```env
VITE_HCAPTCHA_SITEKEY=50b2fe65-b00b-4b9e-ad62-3ba471098be2
VITE_WEB3FORMS_ACCESS_KEY=your_web3forms_access_key
```

### 3. Run Development Server
```bash
npm run dev
```

### 4. Build for Production
```bash
npm run build
```
